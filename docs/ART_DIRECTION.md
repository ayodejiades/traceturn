# Art Direction Brief: web2

## 1. Chosen Information Architecture
* **Structural Page Archetype:** `workflow-tool`
* **Visual Metaphor:** High-throughput industrial pipeline with batch status queues and clear stage transitions
* **Target User Moment:** Primary operator handling urgent task execution in web2.
* **Signature Interaction:** 1-click scenario execution populated with high-density realistic seed data.
* **Foreground Evidence:** Ablation benchmark comparison and live sponsor RPC telemetry trace.

## 2. Typography & Palette Stance
* **Display / Body:** Geist
* **Telemetry & Logs:** Geist Mono
* **Surface Foundation:** Flat neutral zinc (#09090b) with exactly ONE saturated accent color.

## 3. Strict Anti-Comp (Anti-AI Slop Mandate)
- Must NOT look like a generic purple-gradient SaaS landing page.
- Zero floating decorative emoji chips or announcement pill badges above headlines.
- Zero asymmetric border-l-4 stripes; enforce 4-sided hairline borders.
- Zero fake precision metrics (e.g. 99.99%); use organic domain measurements.
- Zero unmotivated particle animations or ambient glowing blobs.
